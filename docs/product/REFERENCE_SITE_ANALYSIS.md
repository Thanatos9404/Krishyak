# Reference design analysis

Observed 3 October 2026: [OneSoil Platform](https://onesoil.ai/en/platform).
Screenshots at 1440×900, 1280×800, 768×1024, 390×844 and 360×800 are in
ignored `output/product/reference/`. Desktop dropdown and mobile menu were opened.
The public reference was inspected without signing up or submitting a form.

## Typography and layout

The rendered font is Geologica: a rounded, geometric sans with a human tone.
The mobile H1 computes to 36 px, weight 500, tracking −1.44 px. Wide headings
are larger; body text is quieter, with relatively short centered introductions.
The background computes to `rgb(246,244,239)`. A wide floating capsule header
contrasts with generous open space, centered titles and large product visuals.
Feature groups alternate image-led sections and modular cards. Mobile stacks
the story vertically and turns the footer into expandable navigation.

## Visual language

Warm neutral surfaces, dark ink, green accents, broad rounded containers and
limited shadows. Actual field maps and interfaces explain capabilities. Large
visuals carry the story; individual features use concise labels. Dense product
screenshots can become difficult to read on small screens, so Krishyak will use
original, simplified previews and a separate real demonstration workspace.

## Navigation and interactions

Desktop Products expands the header into a large dropdown and dims the page.
Mobile opens a dark, full-height menu with prominent actions and accordion
groups. The site uses previous/next controls on feature carousels and FAQ
expansion. The floating header remains available while scrolling. The inspected
flow keeps normal browser scrolling. Exact animation durations were not
instrumented; visual observations are not timing measurements.

## Krishyak reinterpretation

Use the openly licensed Geologica family, a darker agricultural green, ivory,
sage and controlled earth tones. Create an original leaf/field symbol, original
copy and interface previews. Real, licensed photographs provide context for
fields, people, crops and markets. None of OneSoil's photographs, screenshots,
logos, testimonials, impact statistics or product claims are reused.

Public pages can tell a visual story. Daily farmer work uses a quiet sidebar or
five-destination bottom navigation, large touch controls, conclusion-first
evidence cards and optional details. Avoid cinematic motion in private workflows.
Keep reduced-motion support, visible focus and plain error recovery.
