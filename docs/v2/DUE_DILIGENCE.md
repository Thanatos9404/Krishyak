# Evidence package for demonstrations and funding

Present the product as a private field-evidence workflow with transparent
decision support. Demonstrate synthetic development identities only with the
visible development banner. A public demo is not a completed farmer pilot or
government authorization.

The package includes [current-state audit](CURRENT_STATE_AUDIT.md),
[implementation plan](IMPLEMENTATION_PLAN.md), architecture/domain/API/database,
security/privacy/threat model, offline design, deployment/restore instructions,
active model metrics, test report, costs and explicit limitations.

Claims that can be substantiated: owner-scoped storage/consent/rights engineering;
stored quality-aware satellite adapter and manual fallback; deterministic Today;
private image results and consented feedback/review; optional device cache and
bounded sync; scoped pilot records; tested migrations/container/browser flows.

Claims that cannot be made: independently field-validated disease accuracy above
the recorded 57.21% external result, guaranteed income/yield improvement,
government approval, authorized identity registry access, regulatory compliance,
physical-device certification or production SLA. Model runtime smoke and user
feedback do not replace independent evidence.

Track real pilot recruitment/retention with a defined denominator, consent
withdrawal, usable evidence coverage, response/inspection time, reviewer agreement,
provider error/missingness, support burden and measured costs. Do not invent
baseline, impact, revenue, savings, partnerships or grant endorsements. Dataset
license/acquisition gaps must be disclosed before external redistribution.
