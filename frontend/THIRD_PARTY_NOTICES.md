## Magic UI / 21st.dev

`src/components/ui/ShineBorder.jsx` adapts Magic UI ShineBorder for this React/CSS project, with an earthy palette and reduced-motion support.
21st listing: https://21st.dev/@dillionverma/components/shine-border
Source: https://github.com/magicuidesign/magicui/blob/main/apps/www/registry/magicui/shine-border.tsx
The source uses a radial gradient and composited CSS masks. No new runtime dependency is needed.
